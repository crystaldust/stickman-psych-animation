# 文案风格指南（制作手册）

> `/write-script` 每次写稿前都会读这份文件。标着【待你确认】的部分是根据目前的对话起的草稿，请按你自己的想法修改。

## 1. 频道定位【待你确认】

- **做什么**：用火柴人动画讲心理学、恋爱和亲密关系。
- **为谁做**：正在经历或刚走出一段消耗型关系、反复内耗、睡不着的人。
- **想给观众什么**：陪伴和被理解的感觉，而不是答案或说教。看完觉得「原来不只我这样」「我可以对自己温柔一点」。
- **不是什么**：不是情感导师，不教「怎么挽回」「怎么拿捏」，不贩卖焦虑。

## 2. 语气【待你确认】

- 用「你」来称呼观众，像深夜给朋友发的一段长消息：温和、克制、真诚。
- 先承认感受，再谈道理。不说「你应该」「你必须」，改成「也许可以」「你可以试试」。
- 不站在高处总结人生，也不用「醒醒吧」「格局打开」这类居高临下的说法。
- 少用感叹号。允许留白，有些问题可以不给答案。
- 避免空洞的鸡汤口号，比如「做更好的自己」「一切都会好起来的」。要说就说具体的。

## 3. 结构

参考频道的有效结构，但不要每篇都套同一个模板：

1. **钩子**（前 15 秒）：一个具体的场景或一个反常识的问题。比如「凌晨两点，你又打开了他的聊天框」，而不是「今天聊聊依恋」。
2. **承认**：说出观众此刻的感受，让他觉得被看见。
3. **一个观点**：引入一位思想家的观点或一个心理学概念。**每篇只讲透一个**，不堆砌。
4. **例子**：用生活化的场景把观点讲明白。场景要自己设计，不借用参考频道的例子。
5. **换个角度**：把观点往前推一步，或者给出一个温和的、可以做到的小行动。
6. **收尾**：一句可以带走的话，是陪伴，不是命令。

## 4. 篇幅

- 每篇 1.5 到 3 分钟，约 650 到 1300 字。参考频道的语速实测约每秒 7 个字。
- 一句一行，方便配音和对画面。

## 5. 引用规范（硬性要求）

- 只引用出处库里判定为 **原话（verbatim）** 或 **意译（paraphrase）** 的内容。
- **原话**：加引号，并注明作者和作品，比如：克尔凯郭尔在日记里写过：“生活只能向后理解，却必须向前生活。”
- **意译**：不加引号，写成「弗洛伊德在《论自恋》里表达过类似的意思：……」。
- **误引（misattributed）不能当成名人原话来用。** 可以作为话题来讲，比如「网上流传一句『荣格说……』，其实荣格的原著里查不到这句话」。这本身就是我们和参考频道的差异化。
- **无法核实（unverified）的不用。**
- 每篇草稿的 front matter 要列出所有引用的出处。

## 6. 原创规范（硬性要求）

- 只借用**观点和出处**，不借用参考频道的句子、例子和标题句式。
- 写完必须运行 `uv run stickman draft check <草稿>`：连续 15 个字以上和已采集文案重合，就要改写。引号里的直接引用不计入。

## 7. 禁忌

- 不做诊断，不说「你这是抑郁症」「你这是回避型依恋」。可以说「心理学里有个概念叫……，也许能解释一部分」。
- 涉及自伤、自杀的话题，必须在结尾和视频简介里附上心理援助热线。**发布前核实最新的热线号码**，不要凭记忆写。
- 不攻击、不贬低前任或某一类人。

## 8. 画面提示

每段文案后面可以加一行画面提示，方便后期制作：

```
凌晨两点，你又打开了他的聊天框。
> 画面：黑暗房间里火柴人坐在床上，手机屏幕的光照在脸上；CRT 雪花闪一下切入
```

- 视觉元素：火柴人，CRT 电视雪花背景，老电影的抖动和颗粒感。
- 背景音乐：Midwest Emo 风格。**版权音乐要先解决授权**，之后再在这里登记可以用的曲目。

## 9. 草稿格式

```markdown
---
title: 标题
topic: 选题一句话
duration_estimate: 约 2 分 10 秒（900 字）
sources:
  - author: 索伦·克尔凯郭尔
    title: 日记（1843）
    locator: JJ:167
    verdict: verbatim
status: draft
---

正文，一句一行……
```
